Educational explanation

6. Steel Table & Bolt Suggestions (preliminary)

Searches the limited section catalog and counts 2–30 bolts. Section yielding, rupture, block shear, bolt shear, angle/gusset bearing and long-joint reduction are checked for the stated arrangement. Not a complete connection design.

Preliminary only: verify bolt threads, real Steel Book, edge type, gusset net/block shear, all detailing, shear lag, eccentricity and slenderness from the actual sketch. A green result does not mean full structural safety.

Limits: This PASS only covers the three implemented checks for the assumed bolt layout. It does not verify all possible block-shear paths, bolt strength/bearing, gusset capacity, detailing or member slenderness. Academic/professional verification using the actual standard and Steel Book is still required.

Reference provisions: IS 800:2007 Clauses 6.2 (gross yielding), 6.3.3 (single-angle rupture with shear lag), 6.3.4 (double-angle rupture), 6.4.1 (block shear), Table 5 (partial factors). The clause 6.3.3 beta cap is adjusted for Amendment No. 1 (2012). Source data: section shortlist from the project's data/angles.csv, which must be compared with your institution's Steel Book. This preview uses the same equations as engine.py but is an independent JavaScript implementation for offline use.
